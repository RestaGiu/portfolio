# Resta Giuliano — Product Designer Portfolio

Portfolio pessoal de Resta Giuliano, Product Designer focado em produtos B2B SaaS, dados e IA. O site apresenta estudos de caso, experiência e canais de contato em inglês, italiano e português.

## Stack

- Next.js 16
- React 19 e TypeScript
- Tailwind CSS
- Framer Motion e GSAP

## Desenvolvimento local

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Verificação e produção

```bash
npm run check
npm run build
npm run start
```

## Conteúdo

O conteúdo editorial e os dados estruturados dos projetos ficam em `content/site.ts` e `content/i18n.ts`. Imagens e marcas ficam em `public/`.
